# 🍔 Swiggy Sales Performance Dashboard | Power BI

> **Interactive sales analytics dashboard built in Power BI using DAX to monitor food-delivery sales performance across daily, weekly and monthly trends.**

![Swiggy Sales Dashboard](./swiggy.png)

## 🎯 Business Objective

The objective of this project was to transform sales data into an interactive management dashboard that makes performance trends easier to monitor and supports faster business decision-making.

The analysis focuses on **how sales move over time, where performance changes, and how management can investigate those changes through interactive reporting**.

## 📌 KPI Snapshot

The dashboard highlights key sales-performance KPIs designed for quick management review:

- **Total Sales** — overall sales value generated
- **Total Orders / Transactions** — overall order volume
- **Average Order Value (AOV)** — average sales value per order
- **Total Quantity** — total quantity/items sold
- **Sales Trend** — daily, weekly and monthly movement in sales

> **Note:** KPI values are intentionally not duplicated in the README so the documentation stays synchronized with the live dashboard screenshot and avoids publishing figures that may change during analysis.

## 📊 Analysis Covered

- Daily sales performance and movement
- Weekly sales trends for short-term monitoring
- Monthly sales trends for broader performance review
- Period-based sales comparison
- Identification of stronger and weaker sales periods
- Interactive filtering for focused analysis

## 🧠 DAX-Driven Analysis

This project was developed **only in Power BI using DAX**. No Excel or Power Query workflow is claimed for this project.

The project demonstrates practical use of:

- Aggregation measures
- Filter context
- DAX-based KPI calculations
- Daily / weekly / monthly analysis logic
- Time-based comparisons
- Measures designed for interactive dashboard filtering

## 💼 Business Value

The dashboard can support a sales/operations team by helping them:

1. Monitor sales performance at multiple time levels.
2. Track core KPIs from a single management view.
3. Identify stronger and weaker periods quickly.
4. Investigate changes in sales trends through interactive filters.
5. Compare short-term movement with broader monthly performance.
6. Convert recurring DAX calculations into a reusable management-reporting view.

## 🔍 Analyst Perspective

The key learning from this project was moving beyond static charts and using **DAX measures + filter context** to create reusable business metrics.

**Raw Sales Data → DAX Measures → KPI Monitoring → Trend Analysis → Business Interpretation**
